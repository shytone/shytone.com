模型路由生态与 token 降价

纯省钱的「路由」会商品化，但「切换能力」会以别的理由转世。

现状：opencode 内置 small_model / 失败回退；生态里有 RouteLLM、Not Diamond、LiteLLM。多数「自动选模型」只覆盖固定场景。

token 降价会淘汰成本驱动的路由——价差趋近于零时，只剩开销。但「切换能力」会转世：

  • 延迟：等 3 秒 vs 20 秒
  • 上下文窗口：最根本——token 免费也塞不进无限信息
  • 质量天花板：frontier 推理成本是物理约束
  • 本地 / 隐私 / 离线

判断：纯省钱的 cost-tiering 路由 2-3 年内会大幅商品化。
