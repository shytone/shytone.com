代码贬值，意图升值

当代码的生产成本趋近于零，最值钱的东西变成了「你究竟要什么，以及如何证明你做对了」。

过去，写代码是稀缺能力，价值集中在「手写实现」。AI 把生成成本压到接近零，「写代码」不再是一道护城河。

稀缺的东西向上迁移：需求、规格、架构、领域知识、约束与验收标准——统称为「规约」。代码成为派生产物，规约承载意图，AI 只是翻译器。

但这并不是简单的「代码→规约」替换：代码仍是行为的事实来源；规约要变成可运行的代码，就必须精确到接近代码——所以规约本身会「代码化」，可版本、可测试、可校验。

很多产品的资产从来不只是代码：数据、用户、生态、品牌、信任。AI 只是降低了「代码」那一部分的成本。

真正的稀缺是验证与判断：怎么知道规约正确？怎么知道实现正确？

结论：资产从「会写代码」迁移到「会精确地规定 + 可靠地验证 + 拥有反馈闭环」。
