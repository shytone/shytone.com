TDD 没有死，它升级成了「驱动意图」

反直觉：传统 TDD 验证实现，Agent 时代的 TDD 首先是验证理解。

传统「红 - 绿 - 重构」：红阶段人写失败测试，绿阶段实现，重构把关。

vibe coding 最大的风险是省略「红」阶段——「写测试麻烦」恰恰是人最想偷懒的地方，而 Agent 生成的代码最需要测试兜底。

测试在 Agent 时代多了一层作用：测试失败 = 意图传达失败。

结论：红阶段写的不是代码，是你对「成功」的定义。
