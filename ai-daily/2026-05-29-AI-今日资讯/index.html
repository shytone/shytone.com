🤖 AI 今日资讯 | AI Daily

1. OpenAI GPT-5 API 正式开放，定价策略大幅调整

OpenAI 官方宣布 GPT-5 API 正式向开发者开放。新的定价策略进行了重大调整：输入 Token 价格下调至 $2/1M，输出 Token 下调至 $8/1M，相比 GPT-4o 降低了近 60%。同时推出了新的”深度推理”模式（Deep Reasoning Mode），适用于需要复杂推理的数学和编程任务，价格更低但延迟略有增加。

2. 阿里云通义千问 3.0 发布，长文本处理能力提升 10 倍

阿里云发布通义千问（Qwen）3.0 系列模型，新版本将长文本处理能力从 10 万 Token 提升到 100 万 Token。在 Q&A 理解、逻辑推演和中文创意写作方面提升显著。新模型还支持”多模态插件”机制，可以根据任务需求动态加载专业领域的知识模块。

3. Notion AI 推出 Classroom 功能，教学场景支持

Notion 宣布其 AI 功能新增 Classroom 模式，专为教学场景优化。教师可以使用 Notion AI 自动生成课程大纲、创建随堂测验、以及批量批改学生作业并给出个性化反馈。学生则可以在 Notion 页面中调用 AI 辅导助手，获得即时的学习指导。目前该功能对教育机构免费开放。

4. Runway Gen-3 Alpha 开放 API，支持企业视频自动化

Runway 正式开放 Gen-3 Alpha 视频生成模型的 API 接口，企业用户可以通过程序批量生成营销视频。API 支持自定义风格迁移、批量添加水印、以及自动生成视频封面。新定价按照生成的分钟数计费，适合有大量视频内容需求的内容团队。

5. 百度文心一言 4.0 企业版发布，支持私有化部署

百度发布文心一言 4.0 企业版，新增了对私有化部署的完整支持。企业可以在自己的数据中心或私有云环境中运行文心一言，数据完全不出本地网络。4.0 版本还强化了行业专精能力，推出了金融、医疗、制造等垂直行业的定制模型。

6. AI 法律工具 CaseText 获 2 亿美元融资，判断胜诉率

AI 法律辅助工具 CaseText 宣布完成 2 亿美元的 B 轮融资，由红杉资本领投。CaseText 的核心功能是基于历史案例预测诉讼结果的胜诉概率，并推荐相关法律论据。该工具已被超过 2000 家美国律所采用，帮助律师在庭前准备阶段节省约 40% 的时间。

7. GitHub 推出 AI Review Agents，自动化代码审查

GitHub 在 Copilot 之外推出了全新的 AI Review Agents 服务，这是一款专门的代码审查工具。Review Agents 能够自动检查代码的逻辑错误、安全漏洞、性能问题，并给出具体的修改建议和示例代码。目前支持 Python、JavaScript、Go、Rust 等十种主流编程语言。
