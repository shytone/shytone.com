📡 开放鸿蒙（OpenHarmony 5.0）正式发布：万物互联再进一步

开放鸿蒙项目在本周发布了 OpenHarmony 5.0 正式版本，这是自开源以来最重要的版本更新之一。5.0 版本的核心特性是分布式能力的进一步解耦——设备间的协同不再依赖统一的账号体系，可以通过设备指纹（DID）直接建立可信连接。这意味着没有华为账号的老设备也可以参与分布式协同场景，生态壁垒大大降低。

系统层面，ArkUI 5.0 引入了声明式渲染的升级版本”声明式 3.0”，UI 描述代码量平均减少约 40%，同时新增了”响应式布局引擎”，可以根据设备屏幕尺寸与形态自动调整布局。此外，5.0 对 Wi-Fi 7、蓝牙 5.4 和 NFC 碰一碰交互的支持更加完善。手机、平板、智能手表、智慧屏、车机等多设备类型的兼容矩阵进一步扩大。

🕹️ Steam 掌机 Steam Deck 2 曝光：性能对标次世代主机

Valve 内部文件在本周泄露，显示 Steam Deck 的继任者——Steam Deck 2——正在积极开发中。据多方信息，新款掌机将搭载 AMD 定制 APU，采用 Zen 6 架构 CPU 与 RDNA 5 架构 GPU，性能预计是当前 Steam Deck 的约 3 倍，在 1080p 分辨率下可以流畅运行《黑神话：悟空》等级的 3A 大作。

散热系统也做了重新设计：Valve 首次引入真空腔均热板（Vapor Chamber）方案，显著改善了持续高性能输出时的表面温度。屏幕方面，Steam Deck 2 将升级至 7 英寸 120Hz OLED 面板，峰值亮度 1000nit，支持 HDR10。续航方面，新款电池容量提升至 65Wh，综合续航预计达到 8 小时（上一代约为 4-8 小时区间）。官方尚未公布发布日期与售价。

🧩 GitHub Actions 推出 AI Review Agent：代码审查自动化再升级

GitHub 在本周宣布 GitHub Actions 中集成 AI Review Agent 正式版开放使用。这个 AI Agent 可以在 PR 提交后自动分析代码变更，识别潜在 Bug、安全漏洞、性能问题与风格不一致，并给出修复建议与相关文档链接。与此前简单的代码扫描工具不同，AI Review Agent 具备上下文理解能力，可以理解代码的业务逻辑而不仅仅是语法层面。

更重要的是，AI Review Agent 支持”团队规范学习”——通过分析团队历史合并的 PR 数据，Agent 可以学习该团队的代码风格与审查偏好，给出的建议更贴合团队实际规范。这对于规范不完善但希望提升代码质量的中小团队来说是一个高效的工具。AI Review Agent 已向所有 GitHub Enterprise 用户开放。

🌊 Tails 6.0 发布：隐私优先操作系统更新

隐私操作系统 Tails 在本周发布了 6.0 版本，这是基于 Debian 13 的重大更新。6.0 版本内核升级至 Linux 6.12，引入了”完整性验证启动”（Measured Boot）机制：在系统启动过程中记录每个组件的哈希值，用户可以在另一个可信设备上验证启动过程的完整性，有效防止供应链攻击。

网络层面，Tails 6.0 默认启用了”所有流量强制走 Tor”模式，并新增了对 Snowflake、Obfs4 与 meek 混淆协议的自动选择机制——在网络审查严格的环境中，系统会自动选择最稳定的混淆协议。此外，新的”安全剪贴板”功能会在 60 秒后自动清除剪贴板内容，防止敏感信息泄露。Tails 依然是隐私保护与安全研究领域的首选操作系统之一。
